# CommandPaletteEmpty

**Grupo:** Misc · **Pacote:** `@pharos-ds/core`

Exibição de estado vazio para a área de resultados. Renderizado automaticamente pelo CommandPalette para estados sem resultados e sem consulta.

## Importação

```tsx
import {CommandPaletteEmpty} from '@pharos-ds/core/CommandPaletteEmpty';
```

## Exemplos

### Área interativa

```tsx
import {CommandPaletteEmpty} from '@pharos-ds/core/CommandPalette';

<CommandPaletteEmpty />
```
